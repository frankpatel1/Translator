# Translator

## 🌐 Overview

Translator is a web-based language translation application developed using HTML, CSS, and JavaScript. The application allows users to translate text between multiple languages through an intuitive and responsive interface.

Designed for simplicity and usability, the project demonstrates API integration, asynchronous JavaScript operations, DOM manipulation, and modern front-end development practices. It provides a convenient solution for translating text while offering additional features such as speech playback and clipboard support.

## ✨ Features

* Translate text between multiple languages
* User-friendly and responsive interface
* Language selection dropdowns
* Swap source and target languages
* Instant translation results
* Copy translated text to clipboard
* Text-to-speech support
* Mobile-friendly design
* Fast and lightweight performance

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Translation API Integration
* Web Speech API

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser such as:

* Google Chrome
* Mozilla Firefox
* Microsoft Edge
* Safari

### Installation

Clone the repository:

```bash
git clone https://github.com/frankpatel1/Translator.git
```

Navigate to the project directory:

```bash
cd Translator
```

Open the application:

```bash
index.html
```

or simply double-click the file to launch it in your browser.

## 📖 Usage

1. Enter text in the source language field.
2. Select the source language.
3. Choose the target language.
4. Click the translate button.
5. View the translated output instantly.
6. Copy the translated text if needed.
7. Use speech playback to hear the pronunciation.
